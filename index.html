How it works

Open it.
Start writing.

I

Download one file

ArcWright is a single self-contained HTML file. No installation, no account, no app store. Download it, save it wherever you keep your writing, and open it in any browser. That's it.

II

Create a project

ArcWright opens to a project directory. Create a project for each story you're working on — each one is a fully isolated world with its own characters, factions, locations, lore, and timeline. Switch between them instantly, nothing bleeds across.

III

Build your world

Create character folders — multiple sheets per folder for different versions or time periods. Add your factions, your locations, your lore. Everything saves automatically to its own isolated storage slot per project.

IV

Export anytime

Export any project as a JSON file to back it up or move it to another device. Export any individual character sheet as a clean HTML document that opens in Word or Google Docs. Duplicate a project to fork a story in a different direction while keeping the original.

V

Your work stays yours

Nothing you create in ArcWright ever leaves your computer. No servers, no syncing, no data collection. Your stories belong entirely to you — ArcWright is just the room you keep them in.
