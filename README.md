# ArcWright
ArcWright — World-building studio for fiction writers
ArcWright is a complete world-building and character development tool that runs as a single HTML file in your browser. No installation, no account, no subscription. Everything you create belongs entirely to you.
→ arcwright.io — visit the site to learn more and get the app.

What's inside
Seven integrated modules in one offline file: Projects, Character Sheets, Factions, Locations, Lore Codex, Story Overview, and QuickNotes. Build your characters, your world, and your story structure in one place.
